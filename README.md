# ComicBot

Отдельный Telegram-бот для ежедневной генерации и публикации авторских комиксов.

## Текущий сценарий

- Генерация изображения через Hugging Face Space `Qwen/Qwen-Image-2.1`.
- Использование утверждённого изображения героини как identity reference.
- Сохранение результата на VPS.
- Публикация в Telegram-канал через отдельного бота `@zentestmp_bot`.
- Плановая публикация ежедневно в 09:00 по московскому времени.
- Первый автоматический выпуск — отдельный однократный запуск после настройки расписания.

## Безопасность

Секреты хранятся только в локальном env-файле на VPS. Файл `.env` не добавляется в Git. Не помещайте токены, готовые изображения и журналы запусков в репозиторий.

## Разработка

Python 3.12. Установка зависимостей:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в локальный `.env` и заполните секреты. Для VPS путь к env-файлу будет задаваться конфигурацией службы.

## Статус

Начальный каркас проекта. Генератор, сценарии выпусков, защита от повторной публикации и systemd timers будут добавлены после переноса проверенной логики с VPS.
